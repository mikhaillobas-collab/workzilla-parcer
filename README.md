# Work-zilla AI Agent: Автоматизированный парсер и откликщик с оценкой через Gemini LLM

Интеллектуальная система автоматизации для биржи фриланса **Work-zilla** (`https://client.work-zilla.com/freelancer`). 
Бот мониторит ленту новых заказов, фильтрует их, оценивает возможность **100% автономного выполнения только силами языковой модели (Gemini)**, автоматически удаляет/скрывает нерелевантные задачи и отправляет лаконичные сопроводительные отклики с указанием стека.

---

## 🚀 Ключевые возможности

1. **Строгий LLM-скоринг (Gemini 2.5 Flash)**:
   - Проверяет каждую задачу на выполнимость без участия человека (онлайн, код, тексты, переводы, парсинг, формулы Excel).
   - Автоматически отсеивает любые задачи с физическим участием, звонками, верификацией по паспорту/сим-картам или накруткой отзывов (Авито, Яндекс.Карты, соцсети).
2. **Поддержка Proxy для Gemini**:
   - Встроенная работа через `HTTP` и `SOCKS5` прокси для надежного обхода региональных блокировок Google API.
3. **Обход антифрода Work-zilla (CDP / Chrome DevTools Protocol)**:
   - Бот подключается напрямую к вашему обычному запущенному Chrome (`--remote-debugging-port=9222`).
   - Вы авторизуетесь на бирже сами, проходите капчи и проверки Cloudflare — биржа видит реальный доверенный браузер.
   - Рандомизированные задержки (15–45 сек) перед отправкой отклика для имитации живого человека.
4. **Очистка очереди**:
   - Неподходящие заказы автоматически скрываются на сайте кнопкой «Скрыть», чтобы не засорять ленту.
5. **Безопасный режим (Dry-Run)**:
   - Возможность запустить бота в режиме симуляции, чтобы в консоли видеть вердикты LLM и сгенерированные тексты откликов до включения реальных ставок.
6. **Локальная база данных (SQLite)**:
   - История всех проверенных заказов, причин отказа, статусов и текстов откликов. Никаких повторных оценок или дублей.

## 🛠️ Установка и настройка

### Шаг 1. Клонирование и зависимости
Убедитесь, что установлен Python 3.10+:
```bash
pip install -r requirements.txt
```

### Шаг 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
```ini
# Ключ Google AI Studio (https://aistudio.google.com/)
GEMINI_API_KEY=AIzaSy...

# Прокси для запросов к Gemini (SOCKS5 или HTTP с US/EU геолокацией)
PROXY_URL=http://user:pass@proxy-server.com:8080

# Режим подключения к браузеру
BROWSER_MODE=cdp
CDP_URL=http://127.0.0.1:9222

# Безопасный режим (сначала рекомендуется true для тестов)
DRY_RUN=true
```

### Шаг 3. Запуск Chrome с отладочным портом (для режима CDP)
Для безопасной работы запустите ваш Chrome с флагом `--remote-debugging-port=9222`:

**На Windows (в PowerShell или командной строке):**
```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-bot-profile"
```
1. В открывшемся окне Chrome перейдите на `https://client.work-zilla.com/freelancer`.
2. Авторизуйтесь под своим аккаунтом исполнителя.
3. Убедитесь, что лента заказов открыта.

## 🧪 Тестирование компонентов

Перед запуском боевого цикла запустите тесты:
```bash
python test_evaluator.py
```
Тест проверит:
* Корректность загрузки конфигурации и стоп-слов;
* Работу базы данных SQLite;
* (Если указан ключ) тестовую классификацию синтетических задач через Gemini API и прокси.

## ▶️ Запуск бота

Запустите скрипт мониторинга:
```bash
python run.py
```

1. Бот подключится к открытой вкладке Chrome.
2. При появлении новых заказов:
   - Проверяется бюджет (минимальная цена в `config.yaml`).
   - Проверяется стоп-лист (`config/stop_words.txt`).
   - Отправляется запрос в Gemini для оценки выполнимости и генерации отклика.
   - Неподходящие заказы **скрываются** в интерфейсе биржи.
   - Подходящие заказы получают отклик (в режиме `DRY_RUN=true` отклик просто логируется в терминал).
3. Для остановки нажмите `Ctrl + C`.

## ⚙️ Тонкая настройка (`config/config.yaml`)

- `filters.min_price`: Минимальный бюджет заказа (по умолчанию `150` руб).
- `filters.max_proposal_chars`: Максимальная длина отклика (по умолчанию `320` символов).
- `filters.hide_rejected_on_site`: Автоматически скрывать отсеянные задачи (`true`/`false`).
- `delays.min_apply_delay_sec` / `max_apply_delay_sec`: Случайная пауза перед отправкой (по умолчанию `15`–`45` секунд для защиты от детекции).
- `config/stop_words.txt`: Список тем, которые сразу бракуются (звонки, сим-карты, Авито, выкупы, оффлайн).
